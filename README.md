# @rezaul/react-native-printer-kit

Direct Bluetooth POS/thermal (ESC/POS) printer integration for React Native on Android — print raw text, images, PDFs, and full HTML/CSS content including Bangla and other non-Latin scripts.

## Installation


```sh
npm install @rezaul/react-native-printer-kit
```


## Usage


```js
import { multiply } from '@rezaul/react-native-printer-kit';

// ...

const result = multiply(3, 7);
```
